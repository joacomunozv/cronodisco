# Cronodisco

Mesa de juego musical para iPad: ordena canciones por año en tu línea de tiempo.

- Reproduce fragmentos de 30 s desde la API de Deezer (uso privado, no comercial).
- El mazo se carga desde un archivo JSON o CSV (artista, titulo, ano, deezer opcional) y queda guardado en el dispositivo.
- Instalar en iPad: abrir en Safari → Compartir → Agregar a pantalla de inicio.
