# Cronodisco

Juego musical para iPad: ordena canciones por año en tu línea de tiempo.

- **Administrador (iPad):** abre `…/cronodisco/#admin`, ingresa con tu correo, elige mazos, crea una sala y ve quién se une.
- **Jugadores (celular):** escanean el QR de la sala o escriben el código.
- Audio: fragmentos de 30 s desde la API de Deezer (uso privado, no comercial).
- Datos: Supabase (`schema.sql` tiene tablas, seguridad RLS y funciones).
